# 👟 Footwear E-Commerce Store

A clean, responsive, multi-page e-commerce web application built exclusively with **HTML5, CSS3, and JavaScript**. This project showcases a modern online store layout for footwear, complete with interactive shopping elements.

---

## 🚀 Features

- **Responsive Design:** Seamlessly adapts to desktop, tablet, and mobile screens.
- **Product Showcase:** Dynamic grid layouts displaying shoes, pricing, and descriptions.
- **Interactive Shopping Cart:** JavaScript-driven cart functionality allowing users to add, update, and remove items.
- **Filtering & Navigation:** Interactive navigation menu and category filtering.
- **Modern UI/UX:** Clean styling, hover effects, and smooth UI interactions.

---

## 🛠️ Built With

- **HTML5** - Semantic structure
- **CSS3** - Custom styling, Flexbox, and Grid layout
- **JavaScript** - DOM manipulation, event handling, and dynamic cart logic
